# V25 — Ultimate Fusion Experience

## Purpose

V25 compresses the strongest recurring patterns in the supplied 50-site design reference set, the macro-layout/graphic techniques, and the motion-effect catalogue into one Zepto Logic-specific system.

The reference material is treated as a benchmark corpus, not as a template library. No external logo, reference-site imagery, character, customer claim, product claim, proprietary copy, or copied code is embedded.

## Patterns incorporated

- cinematic technology storytelling
- framed technical viewport
- split / half-page composition where useful
- desktop horizontal storytelling with arrow + keyboard control
- vertical mobile equivalent with no forced sideways page movement
- tactile faux-3D / isometric silicon object
- self-drawing signal path
- ambient grid, line and gradient motion
- expressive oversized decorative typography
- asymmetrical card rhythm within a controlled grid
- geometric / Bauhaus-like accents
- glassmorphic technical readouts
- hover, focus, pointer and keyboard microinteractions
- scroll-driven progressive enhancement where supported
- strong proof, technical-route and conversion architecture
- visitor-controlled Full / Calm / Still motion
- local Web Performance telemetry hooks for future analytics wiring

## Patterns deliberately not forced

- no horizontal-scroll trap on mobile
- no artificial preloader that delays an already-static site
- no fake shopping cart for consultative B2B semiconductor IP/services
- no mascot or character animation without an actual brand role
- no AR/VR claim without a genuine AR/VR use case
- no claymorphism/neumorphism where it would weaken engineering credibility
- no third-party 3D library merely for decoration
- no social-account link unless an official profile is verified

## New homepage engineering theatre

The older four-box process strip is replaced by a richer five-stage system:

1. Define
2. Architect
3. Implement
4. Verify
5. Prove

Selecting a stage updates the 3D silicon object, engineering readout, signal path and progress state. Desktop users can use horizontal scrolling, arrow buttons or keyboard arrows. Mobile users receive a normal vertical reading flow.

## Global experience controls

A compact Motion control offers:

- Full
- Calm
- Still

The choice is stored only in localStorage. System reduced-motion remains supported. Still mode pauses video and retires continuous decorative motion.

## Performance instrumentation

V25 records a small in-page performance sample to the existing dataLayer hook:

- Largest Contentful Paint
- Cumulative Layout Shift
- DOMContentLoaded timing
- load timing

No new external analytics request, cookie, fingerprinting system or third-party telemetry service is added.

## V24 QA issue closed

V24 QA Run 123 did not expose a product/UI defect. The functional, media and mobile tests had progressed successfully; the final full-page screenshot artifact test exceeded its 120-second test timeout after the page/device matrix and high-resolution media expanded.

V25 changes that artifact job to:
- 300-second test budget
- DOMContentLoaded instead of full media network-idle
- paused videos for deterministic captures
- screenshot animations disabled
- progressive-reveal content forced visible for useful review artifacts
