# V20 — Prism Interaction System

## Source audit
The user provided several free TemplateMo downloads. They were treated as an interaction/design reference library rather than copied as a finished theme.

Patterns studied:
- Rainbow: colour families, table/card variety and strong colour coding.
- SEO Dream / DigiMedia / Tale: animated section reveals, progress motifs, tab/carousel composition, decorative edge shapes and gradient CTA treatment.
- Neural Glass: luminous glass surfaces, neural lines, floating shapes, hexagonal geometry, timeline motion and high-energy cyan/pink/violet accents.
- Sleeky Pro: coral–mint gradients, progress/ring motifs, clean tabbed content and futuristic stat treatments.
- Hyperluv: editorial colour blocks, acid lime/orange/pink, oversized interactive type, full-bleed moving ticker, tactile button offsets and slide-progress energy.

## What V20 reinterprets for Zepto Logic
No template logo, stock imagery, demo copy or third-party visual asset is used. V20 reimplements the strongest interaction ideas as original semiconductor-specific components:
- interactive reusable-IP / RTL / verification / FPGA playground
- animated hexagonal die and signal orbit system
- vivid metric bento
- editorial full-colour engineering rail
- desktop section navigator
- animated spectrum heading rules
- card depth / restrained pointer tilt
- tactile CTA ripple
- page-hero prism shards
- global section colour chapters
- gradient footer crown

## Professional constraints
- all factual claims stay within existing public staging copy
- no fake customers, testimonials, deployments or logos
- reduced-motion disables continuous movement
- mobile collapses complex layouts cleanly
- keyboard semantics retained for the tab interaction
- staging noindex/nofollow and production canonical safeguards remain unchanged
