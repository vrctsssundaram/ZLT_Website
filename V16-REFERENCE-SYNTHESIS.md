# V16 Reference Synthesis Checkpoint

This checkpoint records the design direction before V16 implementation. It does not alter the deployed pages.

V16 objective: global enterprise semiconductor positioning with concise product-first and application-first information architecture; no self-justifying or question-answer lecture tone; no dark background surfaces; strong but professional commercial conversion; evidence placed in Company/News or adjacent to relevant technology; responsive/accessibility/backend release gates retained.

Reference principles: product-first taxonomy, application-led discovery, useful technical detail before CTA, restrained proof, direct expert contact, enterprise accessibility patterns from recent UI forks, and no wholesale framework/template migration.
