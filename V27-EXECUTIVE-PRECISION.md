# V27 — Executive Precision

## Purpose

V27 responds to CEO review that the previous visual system felt messy, clumsy and overly reminiscent of a cinematic/cyber interface. The objective is not to remove the site's technical capability or conversion architecture; it is to present the same substance with enterprise restraint.

## Design direction

- White and warm-neutral page surfaces
- Deep navy and restrained blue/teal accents
- One controlled dark CTA band rather than repeated dark/neon sections
- Standard responsive typography and consistent alignment
- Square/soft-radius enterprise cards rather than glass/neon objects
- High-quality semiconductor film retained as supporting media, not the entire visual identity
- No aurora, moving colour rail, constellation canvas, neon grid, glowing orbit, animated cursor or continuous decorative ticker
- Purposeful micro-interactions only
- Clear page hierarchy and fewer simultaneous calls to action

## Homepage structure

1. Focused semiconductor proposition
2. Portfolio proof
3. Core capabilities
4. Five-stage engineering path
5. Ways to work together
6. Application contexts
7. Technical discussion inputs
8. Final enquiry CTA

## Required relationship vocabulary

The following CEO-requested terms remain in meaningful commercial/technical contexts:

- Co-creation
- Collaboration
- Co-opting specialist capability
- Co-engineering
- Co-development

They are used to describe engagement models, not scattered decoratively through unrelated technical copy.

## Technical constraints retained

- 13 FPGA-validated soft IP blocks
- Architecture + RTL engineering
- Verification / UVM / lint / CDC/RDC
- FPGA implementation and proof
- Applied hardware R&D
- Search/command palette
- Contact/enquiry workflow
- Responsive mobile navigation
- Reduced-motion support
- Local cinematic media
- Staging noindex/nofollow discipline

## Reference discipline

The visual direction follows the enterprise clarity seen in leading semiconductor/engineering companies: one proposition at a time, controlled media, strong product/capability grouping, concise evidence, generous spacing and restrained motion. No reference-site visual assets or copy are reproduced.
