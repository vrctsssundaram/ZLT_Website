Technical questions

Delivery, customization and evaluation.

How is the IP delivered?

Synthesizable soft IP under a written commercial license, with verification and integration collateral defined for the selected function.

Can the arithmetic be customized?

Yes. Precision, interfaces, parameterization and surrounding datapath requirements can move into a custom RTL scope.

Is it tied to a foundry?

The public portfolio is technology-independent RTL. Implementation results are qualified against the selected FPGA or ASIC target context.

How does NDA evaluation work?

Sensitive source, architecture and detailed characterization can be exchanged after an NDA is in place.

What information helps qualify the fit?

The operation, precision, target platform, interface context and the technical decision the evaluation needs to support.

Related capability

Arithmetic IP can be reused directly or extended through custom RTL engineering.

The reusable portfolio and the engineering team are connected, so a function can move from evaluation into a qualified custom variant when the system needs it.
