# V11 — Zepto Logic Nexus

This branch defines a stateful, corporate-grade, adaptive semiconductor website that behaves as a business-development system rather than a static brochure.

Core principles:
- calm corporate visual language; no neon, gaming, stock-futurism or template-card look
- intent-aware entry states for Buyer, Engineering Lead, R&D Partner, Institutional Partner and Strategic Partner
- modular conversion routes: license, commission, co-develop, collaborate, partner, integrate, evaluate
- stateful recommendations persist across pages via sessionStorage and URL context
- asymmetric but highly ordered layouts with strong typographic hierarchy
- responsive component transformations across compact phone, phone, tablet, laptop, desktop and wide desktop
- low-contrast technical graphics, information rails and activity surfaces fill otherwise dead space
- factual/disclosure safeguards remain unchanged
- staging remains noindex/nofollow

Primary design language:
- typography: Hanken Grotesk + IBM Plex Mono
- palette: graphite, porcelain, titanium, cool steel, controlled cobalt, muted teal
- interaction: quiet, executive-grade, subtle motion, reduced-motion safe
- structure: intent switcher, opportunity matrix, ecosystem map, partnership routes, proof ledger, client journey console, IP/service explorers
