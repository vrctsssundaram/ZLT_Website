# Visual Rebuild V3

This branch is a visual-system replacement for the GitHub Pages staging site.

## Design break from previous versions

- New Geologica + Fragment Mono typography
- New mineral / cobalt / ember palette
- Fixed calibration rail and numbered coordinate navigation
- New semiconductor-reticle background system
- New homepage architecture: frontispiece, commission rail, evidence tape, problem atlas, commercial field, evidence notes, commission band
- IP portfolio rendered as a shared-border die map
- Services rendered as a spatial engagement map
- Full-screen technical search
- Document-colophon footer
- No reuse of the previous teal/Manrope/paper-card visual system

## Content safety

The content, SEO structure and disclosure controls from Website 2.0 remain authoritative. This branch changes presentation and composition without reintroducing legacy claims.
