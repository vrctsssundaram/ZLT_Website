# V21 — Spectacle Layer

V21 increases visual richness without changing the commercial claims or information architecture.

## Progressive web techniques
- CSS cross-document View Transitions for supported browsers.
- CSS scroll-driven animation timelines where supported.
- requestAnimationFrame canvas signal fields with IntersectionObserver pausing.
- GPU-friendly transform/opacity motion.
- no third-party runtime animation library.

## New interaction systems
- animated semiconductor signal-field canvases
- engineering constellation with six technical entry points
- rotating chromatic border beams on interactive cards
- sparse pointer signal sparks on fine-pointer desktops
- multi-hue cursor aura
- moving hero scan beam
- kinetic headline spectrum and underline
- scroll-linked section indices and page-hero prism movement
- animated orbital constellation geometry
- chromatic grain and section seams
- smooth multi-page view transitions

## Performance and accessibility
All continuous V21 effects are disabled under prefers-reduced-motion. Canvas and cursor sparks are also disabled when Save-Data is enabled. Canvases pause when offscreen or the document is hidden. No effect carries essential content.
